# 🚀 Implemented APIs

## ✅ Question 1 – Library Management API
A REST API that manages books in a library system.

**Features:**
- Add new books
- Retrieve all books
- Update book information
- Delete books
- Search functionality

---

## ✅ Question 2 – Student Management API
Handles student records and academic information.

**Features:**
- Register new students
- Retrieve student details
- Update student data
- Delete student records

---

## ✅ Question 3 – Restaurant API
Manages restaurant menu and ordering system.

**Features:**
- Add menu items
- View available food items
- Create customer orders
- Update or remove items

---

## ✅ Question 4 – E-Commerce Product API
Provides product management for an online store.

**Features:**
- Add new products
- Retrieve product list
- Update product details
- Delete products

---

## ✅ Question 5 – Task Management API
Simple task tracking REST service.

**Features:**
- Create tasks
- Update task status
- Delete tasks
- View all tasks

---

## ✅ Question 6 – User Profile API
Manages user accounts and profile information.

**Features:**
- Register users
- View profile details
- Update user information
- Delete user accounts

4. Run the requests.
